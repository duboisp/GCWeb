Pour afficher le formulaire de commentaires de la page, créez une <div> avec l'attribut de données suivant : data-ajax-replace="/sites/feedback/ajax/report-problem-fr.html".

Pour la version HTML simplifiée, un lien doit être créé qui pointe vers la page du formulaire de signalement d'un problème : <a class="btn btn-default btn-block" href="https://www.canada.ca/fr/signaler-probleme.html">Signaler un problème sur cette page </a>

Pour plus d'informations sur le plugiciel Data Ajax, veuillez visiter la page de documentation Data Ajax
