Purpose

[AJAX from DTO]

The global header is a container that displays components that make up the header.

Included components

7 components (3 required and 4 optionals)

  • Authentication (Sign in/Sign out buttons)
  • Breadcrumb trail
  • Government of Canada signature (always required)
  • Language toggle (always required)
  • Site search box
  • Skip link (always required)
  • Theme and topic menu

Before you start

[AJAX from DTO]

Components are used and configured for different page types. Consult the Canada.ca Design system guidance for using these components on Standard, Transactional, and Campaign pages. This includes detail on each of the components listed above.

[Expando] What to do when updating from version 1.0 of the header

Since version 2.0 of the header, the gcweb-menu component is implemented inside a <div class="container">. To ensure the menu appears correctly, make sure it is wrapped in this container. Partial samples illustrating this change appear below.
